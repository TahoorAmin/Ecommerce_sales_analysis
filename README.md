## E-Commerce Sales Analysis:

📌 Project Overview

This project analyzes an e-commerce sales dataset using Python and Pandas. The analysis focuses on understanding sales performance, customer orders, products, categories, cities, and payment methods.

🎯 Objectives

- Explore and understand the e-commerce dataset
- Select relevant columns for analysis
- Filter and sort sales data
- Analyze sales by category, city, product, and payment method
- Calculate important sales statistics
- Identify high-value orders and top-performing products/categories
- Derive meaningful business insights

🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook / VS Code
- CSV Dataset

📊 Analysis Performed

The project includes:
- Dataset overview using "head()", "shape", "columns", and "info()"
- Data selection
- Data filtering
- Data sorting
- Sales analysis by:
  - Category
  - City
  - Product
  - Payment Method
- Total Sales
- Average Sales
- Highest Sales
- Lowest Sales
- Total Quantity Sold
- Total Number of Orders
- Identification of orders with sales above ₹5,000
- Identification of top-performing products and categories
- Key observations and insights



🔍 Key Insights

The analysis helps identify:
- Which categories generate the highest sales
- Which cities contribute the most to revenue
- Which products perform best
- Which payment methods are commonly associated with sales
- High-value orders
- Overall sales and quantity performance
